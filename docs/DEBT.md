# Engineering debt and exceptions

Source: [Engineering Exceptions](../.agents/rules/engineering-exceptions.md).
This is the only debt tracker. No accepted exceptions currently exist.

## Records

Add records as Markdown sections headed `## TD-001 — title` (increment the ID).
Each field is a single `Field: value` line; link supporting detail as needed.
Required fields: Type, Status, Owner, Scope, Cause, Tradeoff, Risk, Safeguards,
Tests, Approval, Trigger, Removal, Related.
Status is PROPOSED, ACCEPTED, RESOLVED or REJECTED. Approval may be PENDING only
before acceptance. Accepted/resolved records require actual dated owner approval
and an evidence reference. Never enter a sample record as real accepted debt.
